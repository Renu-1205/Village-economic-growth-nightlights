# Village Economic Growth from Night-Time Lights

A geospatial economic intelligence project measuring village-level economic growth using satellite-derived night-time luminosity.

## Overview

The project processes approximately **230,000 village polygons across 7 Indian states** and uses **VIIRS night-time light data** to compare luminosity patterns between 2021 and 2025.

The pipeline includes:

* Geospatial data processing and standardisation
* Satellite night-light extraction using Google Earth Engine
* Spatial feature engineering
* Village-level growth measurement
* Composite **Economic Growth Score** construction
* Spatial analysis and visualisation

## Tech Stack

**Python · GeoPandas · Pandas · NumPy · Scikit-learn · Google Earth Engine · VIIRS**

## Data

Due to the size of the raw geospatial and satellite datasets, the complete data is not included in this repository. The repository contains the processing workflow, code, sample outputs, and documentation required to understand and reproduce the analysis.

## Objective

To develop a data-driven framework for identifying and comparing **rural economic transformation** using night-time luminosity as a proxy for local economic activity.
